How sources are processed

All enabled sources are fetched over HTTPS, parsed, deduplicated, then checked against allowlists before a journaled hosts commit. A repeated exact source URL is downloaded only once per list category.

The terminal displays measured entries, duplicate counts, allowlist exclusions, and actual download events. Changes pending means your saved configuration differs from the last successfully applied source set.
