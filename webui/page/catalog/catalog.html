HTTPS image responses (advanced, opt-in)

Generates a private local CA on this device. If you explicitly install and trust that CA in Android, browsers that accept user certificates can see an image for blocked HTTPS hosts. This expands certificate trust: only enable it if you understand the risk. Certificate pinning, app trust rules, ECH and QUIC may still prevent it.

The TLS service listens only on 127.0.0.1:443, never forwards connections or logs requests, and issues certificates only for bindhosts-managed blocked domains. Disabling HTTPS does not uninstall a CA you manually trusted in Android Settings.
